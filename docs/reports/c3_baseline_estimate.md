## 1. 结论（先说做不到什么）

**反推可用作「初值」，但绝不能当成「已标定」。**

| | 值 |
|---|---|
| 材料 / 脉宽 | AlSiC（SiCp/AA2024） / **223 fs** |
| **有效阈值 Fth** | **7.850 J/cm²**（7.85e4 J/m²） |
| **有效去除尺度 δ** | **3652.5 nm**（3.65e-6 m） |
| 训练 / 留出 / 剔除 | 21 / 3 / 0 行 |
| 训练 MAE | 10.295 μm（中位相对误差 **43.7 %**） |
| 留出 MAE | 3.848 μm（中位相对误差 **58.7 %**） |
| 频率档 | 5 档：2 / 5 / 10 / 20 / 40 kHz |
| 跨侧泄漏 | 无 |

⚠️ **40–60 % 的相对误差意味着这不是一个可用的预测模型**，只是"把量级拉对"的起点。
按任务书 §4，它应当用于**给下游核一个初值**，之后由 C4 的标定（单一增益 `a`）继续修正。

## 2. 方法与为什么必须这样做

### 2.1 必须**跨频率**，否则两个参数定不出来

同一 (脉宽, 频率) 下峰值能流 `F` 是**固定的**：

```
Δd = δ·ln(F/Fth)
```

此时 `Fth` 只让整条曲线整体平移，与 `δ` 完全共线 —— 只能定出乘积 `δ·ln(F/Fth)`。
本项把它写成**硬拦截**：训练集只有单一频率时直接报错，不给出参数。

实测可辨识性（把参数翻倍看预测变化）：

| 扰动 | 预测相对变化 |
|---|---|
| `δ × 2` | **1.152**（强） |
| `Fth × 2` | **0.239**（弱） |

即使跨了 5 档频率，`Fth` 仍然欠辨识 —— 因为 `F` 跨 2–40 kHz 对应 11–222 J/cm²，
在 `ln` 尺度上只覆盖约 3 个单位。**这是诚实的限制，不是可以调参调掉的。**

### 2.2 拟合在 log 空间

实验深度跨 0.69–72.96 μm（约 2 个量级）。在线性空间里小深度会被完全淹没，
所以残差取 `ln(D_pred) - ln(D_exp)`。

### 2.3 拟合与检查分开

按**全工况指纹**（脉宽 + 频率 + 速度 + 间距 + 遍数）分组划分，同组必同侧。
留出集里的工况**没有出现在训练中**。

## 3. 闭合验证：机制是对的

为把「代码有问题」和「模型/数据不够」分开，做了一次**闭合验证**：
用已知的 `(Fth, δ)` 生成"实验值"，再让反推把它们找回来。

| | 真值 | 反推 | 相对误差 |
|---|---|---|---|
| `Fth` | 1.0e5 J/m² | 1.0e5 J/m² | **0.00 %** |
| `δ` | 1.0e-6 m | 1.0e-6 m | **0.00 %** |
| 训练中位相对误差 | — | — | **0.00 %** |
| 留出中位相对误差 | — | — | **0.00 %** |

**闭合 0.00 % vs 真实数据 43.7 %** —— 这个对比说明：
反推机制本身正确，真实数据上的大误差来自**模型形式与数据本身**
（单一 `(Fth, δ)` 不足以描述多机制的真实烧蚀），不是实现缺陷。

## 4. 已知限制（不得忽略）

1. **不是独立实测常数**。它来自对**同批实验**的拟合，只有留出集误差说明可迁移性。
2. **只覆盖单一脉宽**。任务书 §4 明确"不假定一组值覆盖全部 223–4000 fs"；
   其它脉宽（500 / 1000 / 2000 / 4000 fs）需各自反推。
3. **`Fth` 欠辨识**（0.239）。若要改善，需要更大跨度的 `F`，或固定 `Fth` 只拟合 `δ`。
4. **与 C4 的 `a` 不同时放开**（两者都控幅度，会互相抵消）。
5. **非正均值行已剔除**（AlSiC 全表 8 行；本窗口 0 行）。纯去除模型解释不了负去除。

## 6. 复现

```bash
PYTHONPATH=src python -c "
from ufdemo.calibration import load_experiment_csv, PredictionSpec, identify_baseline, save_baseline
t = load_experiment_csv('数据/AlSiC.csv')          # 上层 数据/ 目录
spec = PredictionSpec(material_card_file='tests/fixtures/analytic_fixture.json',
                      window_um=20.0, dx_um=0.5)
est = identify_baseline(t.rows, spec=spec, material_family='AlSiC',
                        pulse_duration_fs=223.0, holdout_groups=3, max_nfev=50)
print(est.threshold_J_cm2, est.delta_nm, est.train_median_rel, est.holdout_median_rel)
"
```

约 12 秒（21 行训练 × 若干次迭代 × 每次一次完整求解）。

仅用于展示与端到端测试，**不是真实上游结果**，不得据此得出对照结论。
