# 窗口半径策略实测报告（超阈值开窗）

* 日期：2026-09-15｜批次：L｜决策：`docs/decisions/ADR-0017-window-radius-policy.md`
* 开关：`solver.window_radius_policy = "above_threshold"`（**默认 `"tail_epsilon"`，关闭**）
* 界面：规划与结果 → 「窗口半径策略」下拉（已接）
* 环境：venv `ufdemo`，本机 CPU，`PYTHONPATH=src`

## 0. 本报告修正了两个错误结论（都来自我自己的上一轮）

| # | 曾经的结论 | 实际情况 |
|---|---|---|
| ① | 「成本随网格**超线性**增长，存在 per-event 全局开销」 | **错**。`fixed_geometry` 下域 100/200/400 µm 单事件成本 131/132/138 µs —— **网格涨 16 倍，成本只涨 5%**，不存在 O(网格) 代码路径 |
| ② | `5fa5630`「局部迭代定窗口」是纯语义改进、A/B 逐位一致 | **错，那是回归**。用**窗口内**起伏定尺寸会漏掉邻域里仍能烧蚀的环带（见 §4），已回退 |

## 1. 成本模型：完全由窗口大小决定

固定 1,040 事件、加工区 100 µm、dx 0.5 µm，只换 `geometry_feedback`：

| 域 (µm) | 网格 | `fixed_geometry` µs/事件 | `axial_defocus` µs/事件 |
|---|---|---|---|
| 100 | 40,000 | **131** | 1,445 |
| 200 | 160,000 | **132** | 8,551 |
| 400 | 640,000 | **138** | 13,624 |

⇒ `成本 ≈ 0.06 µs × 窗口格数`。提速只能从**缩小窗口**来。

## 2. 窗口为什么这么大：自增强回路

| 环 | 量 | 值 |
|---|---|---|
| ① | 深度（1 趟，δ=3.6525 µm） | **132 µm**（第一炮中心 `δ·ln(1231)` = 25.99 µm） |
| ② | 离焦（深度 / zR=4.47 µm） | **30 倍** |
| ③ | 光斑（1.33 µm ⇒ ） | **39 µm** |
| ④ | ε 窗口直径（`3.035w`，ε=1e-8） | **237 µm** ≈ 吃满 200 µm 域 |

**窗口里能流超阈值（对去除真有贡献）的格子只占 1.274%**（36,172,632 格中 460,866 格）。

## 3. 半径：与深度无关的**严格上界**

记 `A = F_peak(s=0)/F_th = 2E/(π w0² F_th)`；某格自身离焦 `u = (w_cell/w0)² ≥ 1`，该格处

```
F(r)/F_th = (A/u)·exp(-2r²/(u·w0²))  > 1   ⟺   r² < w0²·f(u)/2,   f(u) = u·ln(A/u)
```

`f` 在 **`u* = A/e`** 处取唯一极大值 `f_max = A/e` ⇒ 对**任意** u 有

```
r < w0 · sqrt(A/(2e))          ← 与当前深度无关的上界（margin ×）
```

* `A ≤ 1` ⇒ 半径 0：任何格子都不可能超阈值，整个平面增量为 0。
* `margin` 默认 **1.25**（1.0 已由严格不等式保证，余量用于吸收网格离散与斜入射平移）。

本算例：`A = 1231` ⇒ `r = 1.3254 × sqrt(1231/5.437) = 19.95 µm`。

## 4. ⚠️ 为什么不能用「窗口内最深点的阈值半径」（`5fa5630` 的回归）

`r(u) = w0·sqrt(u·ln(A/u)/2)` 对 u **非单调**：在 `u* = A/e`（离焦 ≈ 95 µm）处取**峰值** 19.95 µm。

`5fa5630` 改成按**窗口内**的起伏定尺寸后，会出现：光束脚下恰好是**未加工的平地**、
而 20 µm 外是 ~95 µm 深的坑 ⇒ 窗口内跨度趋近 0 ⇒ 窗口缩到 4 µm ⇒
**把 (4 µm, 19.95 µm) 这段仍然能烧蚀的环带整段切掉**。

实测（域 200 / 加工区 100 / dx 1.0，h=6 / N=1，事件 40）：

| | tail 窗口 | 非零增量格 |
|---|---|---|
| 局部迭代（回归版） | 8 × 9 | **20** |
| 真实（严格上界） | 50 × 49 | **87** |

**67 个格子被静默漏掉**，且误差会沿事件累积 —— 最终 25 个候选里 15 个深度不一致
（N=1 恰好没触发，所以当时的 A/B 抽检漏掉了它；**只测 N=1 是无效验收**）。

⇒ **已回退**：默认策略恢复「全网格轴向跨度」口径，与回归前提交 `e79892a` **逐位一致**
（最大绝对差 `0.000e+00`）。超阈值策略用 §3 的上界，二者**全部 25 个候选逐位相同**。

## 5. 实测收益（修正后，均**逐位一致**）

| 算例（事件数） | 既有 `tail_epsilon` | `above_threshold` | 提速 | 裁掉窗口格 |
|---|---|---|---|---|
| 域 200 / 加工区 100 / dx 1.0（1,040） | 1.40 s | 0.24 s | **5.9×** | 92.88% |
| 域 400 / 加工区 100 / dx 0.5（1,040） | 21.91 s | 1.34 s | **16.3×** | 95.34% |
| **域 400 / 加工区 200 / dx 0.5（4,080，界面参数）** | **77.58 s** | **3.21 s** | **24.2×** | 95.41% |

每事件成本：既有 **19.0 ms** → 超阈 **0.79 ms**。
按界面那批 **279,600** 个事件线性换算：**约 88 分钟 → 约 3.7 分钟**。

规划层面（域 200 / 加工区 100 / dx 1.0、25 个候选）：**158.0 s → 33.8 s（4.7×）**，
且 25 个候选的 `mean_depth_um` / `max_depth_um` / `coverage_fraction` / `depth_std_um` / `status`
**全部逐位相同**。

## 6. 口径变化（必须知道）

启用后下列**剂量观测量**的统计范围从 ε 尾部截断半径缩到 §3 的严格上界：

* `surface.cumulative_fluence`、`surface.illumination_count`（也是「受照范围」的来源）
* `fluence_ledger.estimated_intercepted_energy_internal`

因此 `max_domain_truncated_fraction` 会从 ~1e-8 升到 **9–14%**。**这不是域截断**，
是「这部分能流低于阈值、对去除贡献恰好为 0」。求解器收尾警告在启用时**换口径**说明，
并在 `fluence_ledger.threshold_window` 给出 `cells_skipped_fraction`；
规划的每个候选带 `windowRadiusPolicy` 与 `windowCellsSkippedFraction`（启用时另加一条 note）。

`classify_exceedance`（受限阈值协议）**不受影响**：它只看单个事件的 `patch.fluence`，
被裁格子本来就判「未超阈」。

## 7. 用法

界面：规划与结果 → **窗口半径策略** → `超阈值开窗：只算能烧到的区域（快很多）`，
耗时预估会**按策略分口径**重算。

配置层：

```json
{"solver": {"window_radius_policy": "above_threshold", "window_threshold_margin": 1.25}}
```

规划 API：`{"windowRadiusPolicy": "above_threshold", "windowThresholdMargin": 1.25}`。

Python：

```python
cfg.solver.window_radius_policy = "above_threshold"
res = solve(cfg, material)
res.diagnostics["fluence_ledger"]["threshold_window"]   # 口径变化在这里
```

## 8. 待办

1. `mode=grouped`（分组批量）不支持该策略，已写警告；
2. 物理侧 δ 仍是 C3 的「初值级别」值（3652.5 nm）—— 与本策略正交，但深度合理后窗口本来就会小；
3. `tail_epsilon` 口径下的窗口仍是**全网格**跨度（域越大窗口越大、剂量观测量随域变化）。
   若能接受剂量观测量口径变化，可把 §3 的上界同时作为默认策略的**下限**，
   从而让剂量观测量也与域无关 —— 属独立决策，未做。
