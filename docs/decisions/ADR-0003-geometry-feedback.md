# ADR-0003：M0 的几何反馈开关与正入射限制

* 状态：已采纳｜日期：2026-09-10｜批次：A/C（T05/T06）

## 背景

执行细则第 2.3 节要求把“固定几何解析基准”和“当前高度影响轴向离焦”拆成两个
可分别验证的开关；任务书 T05 的完整 G01–G03 需要高度场和积分，因此拆为
T05（标量响应）与 T06（网格与体积）。

## 决定

`solver.geometry_feedback` 取两种值：

* `fixed_geometry`（默认）：**始终用初始表面高度** `h0` 计算轴向距离
  `s = h0 - z_f`，用于 G01/G02 的解析对照。
* `axial_defocus`：用**当前**高度 `h` 计算 `s = h - z_f`，从而
  `w(s) = w0·sqrt(1+(s/zR)²)` 随坑深变化。该模式单独验证，
  **不参与** G01/G02 的线性验收。

另外，M0 **只放开正入射**：

* `beam_patch` 在 `direction_unit` 非 ±z 时抛 `GEOMETRY_UNSUPPORTED`；
* `validate_run` 在配置层同样拦截（不是靠界面禁用按钮）。

## 后果

* 单事件流水线只计算一次光束几何（细则 5.2 第 3 步）；若把 `fixed_geometry`
  关掉而网格在变，仍不会边更新边重算。
* 斜入射、法向厚度转换 `Δh = -a_n/n_z`、可见性/遮挡在 `geometry.py`
  中保持占位并抛 `NOT_IMPLEMENTED`，属 M3（T18）。
