# ADR-0020：光学按名义值**冻结**，单线宽度降级为**对照量**

* 状态：已采纳｜日期：2026-09-15｜批次：L
* 触发：用户 2026-09-15 明确"**这个一定要改**"（此前外部审查列为第 1 条优先修复）。

## 背景：等效光斑反推

`shared_background_patch(threshold_J_m2=…)` 曾经调用
`SharedExperimentBackground.equivalent_spot_radius_m()`：给定脉冲能量与阈值，
**解出**一个使「模型烧蚀宽度 == 声明的实测单线宽度（5 µm）」的等效光斑半径，
然后**替换** `laser.spot_radius_m` 并连带改变 `laser.rayleigh_range_m`。

反推方程（`ablated_half_width_m`）：

```
r_abl(w) = w·sqrt(ln(F0/F_th)/2),   F0 = 2E/(πw²),   E = P_物镜后 / f
解  ablated_half_width_m(w) = 2.5 µm（声明 5 µm 的一半）
```

## 为什么必须改（用户问"频率为什么会影响光斑半径"）

1. **w0 是光学常数**：`w0 = M²λ/(πNA)` 只含 λ/NA/M²。频率、脉冲能量、阈值都不在里面。
   名义值恒为 **w0 = 0.8743 µm、zR = 1.9429 µm**。
2. **反推方程里带着 `E_p = P_物镜后/f`** ⇒ 解出的 w 随**频率**变（实测见下表），
   也随**假定的 F_th** 变 —— 同一工况，阈值写在材料卡里还是通过
   `response_override` 传入，会得到**不同光学**
   （`build_row_config` 只从 `response_override` 取阈值）。
3. **频率依赖被计入两次**：模型本来就有地方让频率影响宽度 ——
   `F0 = 2E/(πw²)` 里的 `E`。名义光学下模型的首击烧蚀宽度本来就随 f 从
   **2.94 µm（200 kHz）变到 4.29 µm（2 kHz）**。再把这个宽度反解回 `w0`，
   等于把同一个频率效应又灌进光学自由度 ⇒ 两个旋钮朝同一方向动 ⇒ 必然过拟合。
4. **连带改 zR ⇒ 改被动离焦**：`w(d) = w0·sqrt(1+(d/zR)²)` 里的 `w0` 与 `zR` 都变了，
   于是不同频率算的**物理过程本身**不同（不只是能量不同）。
5. **解不唯一**：`ablated_half_width_m(w)` 对 w **先增后减**（w 太大时 F0 掉到阈值以下）。
   代码只在 `[w_nominal, w_max]` 的**上升支**上二分 —— 取哪一支是人为选择。
6. **5 µm 是加工结果**：单线宽度是多脉冲扫描的产物（`pitch = v/f` 小于线宽时加深加宽），
   不是单脉冲高斯足迹的直径。**单线宽度 ≠ 单脉冲足迹直径**，这个等号本身需要单独论证。

实测的反推表（本会话用仓库常数复算）：

| f (kHz) | F_th=78496 → w0 (µm) | 连带 zR (µm) | F_th=12890 → w0 (µm) | 连带 zR (µm) |
|---|---|---|---|---|
| 2 | 1.1334 | 3.2649 | 1.0326 | 2.7099 |
| 20 | 1.3254 | 4.4650 | 1.1671 | 3.4622 |
| 40 | 1.4085 | 5.0424 | 1.2203 | 3.7849 |
| 200 | **1.7026** | **7.3678** | 1.3831 | 4.8622 |
| **名义** | **0.8743** | **1.9429** | 同左 | 同左 |

（审查报告给的 1.1334 / 1.3254 / 1.4085 就是 F_th=78496 在 2/20/40 kHz 的值，完全对上。）

## 决定

1. **光学冻结**：`laser.spot_radius_m` 与 `laser.rayleigh_range_m` 一律取
   `derived_waist_m()` / `derived_rayleigh_m()`（名义值，背景文件自带自洽校验），
   与频率、能量、假定的 F_th **无关**。`shared_background_patch` 显式写出
   `rayleigh_range_m`（此前它不在 patch 里，zR 是隐式来的）。
2. **单线宽度降级为对照量**：`_spot_radius_basis` 改为对照记录 ——
   `declared_line_width_um`（仍记录 5.0）、`threshold_j_m2`、
   `model_first_shot_width_um`（名义光学下的**首击**烧蚀宽度）、
   `declared_over_model_width`（比值）。**差得多 → 去
   查 `F_th`/`δ` 或搭接模型，不是去改光斑。**
3. **`equivalent_spot_radius_m()` 保留为诊断工具**：它回答"模型与实测差多远"
   （要多少 w0 才能对齐 5 µm），但**不再参与装配**。
   `plan_for_target` 的 `geometryBasis` 改用同一条冻结路径，
   前端文案同步改为「光斑半径（名义光学，冻结）」。

## 实测影响（诚实记录）

* 光学：任何频率 / 任何阈值下 `w0 = 0.8743 µm`、`zR = 1.9429 µm`（冻结）。
* 20 kHz 下模型首击烧蚀宽度 **3.486 µm** vs 声明 **5.0 µm** ⇒ 声明/模型 = **1.434×**。
  （不同 f 下 1.26–1.70×。）**这条差距现在看得见**，而以前是靠改光斑抹掉的。
* 规划量级变化（域 200 / 加工区 100 / dx 1.0、25 候选、above_threshold、20.9 s）：
  平均深度 **22.4–102.8 µm**（中位 61.9）、覆盖率 **0.316–1.000**（中位 0.658）。
  早期那次「覆盖率由 5–24% 改善到 100%」是把声明的 5 µm 反推进光斑换来的，
  **不是模型变准了** —— 本决定把它撤掉。
* 单元回归：`tests/test_window_radius_policy.py` 的深孔算例最深由 132 µm 降为
  **92.5 µm**（下降 30%）—— 这是光学变准后的**真实**量级变化，不是回归；
  该测试里一处以米为单位写死的阈值（`> 1e-4` m = 100 µm）已改为
  明确的 µm 口径（`× 1e6 > 10`）。

## 验证

pytest **722 passed + 1 xfailed**（+`tests/test_optics_frozen.py` **5 条**：
光学与频率无关、与假定阈值无关、对照量如实、无阈值时仍记录声明宽度、
`equivalent_spot_radius_m` **不得再出现在装配路径里**）。

## 不做 / 待决

* 不在本 ADR 里**重新标定** `F_th`/`δ`：光学冻结之后，剩下的宽度差距
  （模型 3.49 vs 声明 5.0）应当由**下一轮标定**解决 —— 那才是可辨识的拟合。
* 若将来确实需要一个"等效 w0"，必须**在明确工况下标定一次、写清来源与适用范围、
  然后冻结**，并作为独立证据链记录 —— 不得放在拟合循环里逐行重解。
* 审查第 2/5/6/7 条（标定窗口与统计口径、目标覆盖、上游对照、增益绑定）
  仍待决策，见 ADR-0019 末节。
