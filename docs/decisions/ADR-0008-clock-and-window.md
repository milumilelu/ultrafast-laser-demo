# ADR-0008：统一时钟、段区间与局部窗口定位

* 状态：已采纳｜日期：2026-09-10｜批次：B/C（T04/T06）

## 决定一：统一整数时钟与左闭右开

* 所有路径类型共用 `t_j = t0 + j/f`（`paths.clock_index_bounds` 是唯一的
  边界与容差定义处），不在不同路径类型各写一套舍入规则。
* 段区间统一 `[start_s, end_s)`。因此：
  - 固定频率下整条路径**终点不出额外脉冲**；
  - 相邻段在连接时刻**不重复出光**（该时刻归下一段）；
  - 段重叠会被检测出来并抛 `CONFIG_INVALID`，而不是静默取一个。
* 关闭出光期间时钟继续前进，**不在下一条扫描线重置脉冲相位**。
* 定点 n 次照射直接写成 `[t0, t0 + n/f)`，恰好得到 n 个事件（首脉冲 N=1）。

## 决定二：局部窗口用坐标轴定位，而非“最近网格点 + 固定跨度”

早期实现用 `nearest_index(焦点) ± 固定跨度`。当焦点远离计算域时，最近网格点
会吸附到边界，从而**错误地在域边缘制造一小块照射**——这违反“域外不重分配能量”。

现改为 `beam._window_bounds`：在严格递增的坐标轴上用
`searchsorted(axis, focus ∓ r_cut)` 求交，焦点远离时自然得到空窗口。

## 决定三：空窗口仍记录事件

窗口与计算域无交集时，仍保留该事件并累计**发射能量**，但
`estimated_intercepted_energy_intercepted = 0`，不做任何去除，也不把遗漏能量
归一化回剩余网格。能量账本明确写出“发射能量与估计截获能量之差只反映数值裁剪
与计算域边界，不得解释为热损失”。

## 决定四：域截断警告聚合

逐事件打印“尾部超出计算域”会刷屏，且同一物理信息重复。现改为在运行收尾时
聚合一条最大比例警告；`diagnostics.json.fluence_ledger` 里保留逐事件累计值。
