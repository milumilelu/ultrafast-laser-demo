# 高度场数据（「面 → 体」这一级）

**这一级是什么**：**同一工艺、不同加工遍数**下，形貌如何演化 —— 即"平面填充 → 多层体填充"。
它是「点 → 线 → 面 → 体」四级里**唯一真正需要学**的一级（前两级基本是几何，可以算）。

**来源**：光机所原始实验（`.cag` 或已解压的高度 CSV，**原始文件不进 git**）

## 格式约定（所有子目录一致）

- **`.npz`**，内含单个数组 **`z`**
- **float32** —— 保留 0.001 µm 原始精度
  （不用 float16：在 50 µm 量级只剩 ~0.02 µm 分辨率，**会丢数据**）
- 单位 **µm**，**相对高度**（不是绝对深度）
- **无效点 = `NaN`**（原始文件的哨兵）—— **不填 0、不插值**
- **`_index.json`** 记录每个文件的：来源名、尺寸、px 大小、有效比例、z 范围

### 读法

```python
import numpy as np
z = np.load("sic_pass/60组_1_高度.npz")["z"]     # float32, µm, NaN = 无效
print(z.shape, np.nanmin(z), np.nanmax(z))
# 物理坐标: x = (i + 0.5) × px_um,  y = (j + 0.5) × px_um   （px_um 见 _index.json）
```

## ⚠️ 两个材料的视场不一样（跨材料对比要注意）

| 材料 | 物镜 | XY 校准 | 视场 | 数组尺寸 |
|---|---|---|---|---|
| **氧化锆** | 20× | 0.344174 µm/px | **705 × 529 µm** | 1536 × 2048 |
| **SiC** | 50× | 0.278657 µm/px | **285 × 214 µm** | 768 × 1024 |

**视场面积差 ~6 倍** —— 氧化锆一个视场含 2 个加工区，SiC 一个视场通常只含 1 个。
