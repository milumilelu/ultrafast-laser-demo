## ⚠️ 视场与网格差异（跨材料对比**必须**看）

| 材料 | µm/px | 数组尺寸 | **视场** | 说明 |

## 格式约定（所有子目录一致）

- **`.npz`**，内含单个数组 **`z`**
- **float32** —— 保留 0.001 µm 原始精度
  （不用 float16：在 50 µm 量级只剩 ~0.02 µm 分辨率，**会丢数据**）
- 单位 **µm**，**相对高度**（不是绝对深度）
- **无效点 = `NaN`**（原始文件的哨兵）—— **不填 0、不插值**
- **`_index.json`** 记录每个文件的：组号、来源名、尺寸、px 大小、有效比例、z 范围

### 读法

```python
import numpy as np, json
meta = json.load(open("sic_pass/_index.json"))[0]
z = np.load(f"sic_pass/{meta['file']}")["z"]      # float32, µm, NaN = 无效
print(z.shape, meta["px_um"], np.nanmin(z), np.nanmax(z))
# 物理坐标: x = (i + 0.5) × meta["px_um"],  y = (j + 0.5) × meta["px_um"]
```
