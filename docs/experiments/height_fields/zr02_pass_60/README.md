**提取日期**：2026-09-19
**提取工具**：`src/io_cag.py::CagHeightReader`（`physics-guided Mamba-2` 仓库）

---

## 这是什么

**`.cag` 里每一组测量的完整高度场**，转成**压缩 npz**（float32，**保留 0.001 µm 原始精度**）。

| 项 | 值 |
|---|---|
| 组数 | **30** |
| 每组尺寸 | **1536 × 2048** |
| 物镜 / XY 校准 | 20× / **0.344174 µm/px** |
| 视场 | **705 × 529 µm** |
| 高度单位 | **µm**（**相对高度**，非绝对深度） |
| 总体积 | **197 MB** |

> **为什么不用 float16**：原始精度 0.001 µm；float16 在 50 µm 量级只剩 ~0.02 µm 分辨率，
> **会丢数据**。float32 完全保留。

---

## 怎么读

```python
import numpy as np
z = np.load("001_MeasureData20260528095129.npz")["z"]   # (1536, 2048) float32，µm
# ⚠️ 无效点是 NaN（.cag 的 sentinel）—— 不要填 0，不要插值
print(z.shape, np.nanmin(z), np.nanmax(z))
```

**物理坐标**：`x = (i + 0.5) × 0.344174 µm`，`y = (j + 0.5) × 0.344174 µm`

## 与设计表的对应关系

| 层 | 对应 |
|---|---|
| 本目录 30 个 npz | `60Pass组.cag` 的 30 组测量 |
| 每组含 **2 个加工区** | 设计表 `../design_tables_pulse_fs/氧化锆/氧化锆_pass_design.csv` 的**连续 2 行** |
| 60 行设计表 | 15 个工艺条件 × 4 个遍数（N = 1…4） |

**配对方法（关键）**：用设计表的 **`中心Y`** —— **Y 大 ↔ 图像 x 小**（两轴反向）。

| 做法 | 单调性 |
|---|---|
| 假设「x 小 = 先加工」 | 5/15 ❌ |
| **用 `中心Y` 配对** | **10/15** ✅ |

⚠️ 完整配对流程与结论见 `../laser_proc_2026-09-18/README.md`。
