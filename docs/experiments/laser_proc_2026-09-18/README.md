## 一、这批数据回答什么

**「面 → 体」这一级：同一个工艺条件、不同加工遍数，槽深怎么长。**

它是「点 → 线 → 面 → 体」四级里**唯一真正需要学**的一级 —— 前两级（点→线、线→面）基本是几何，可以算。

**数据规模**：`60Pass组.cag` 含 **30 组测量**、每组 2 个加工区 ⇒ 60 个加工区。
设计表 60 行 = **15 个工艺条件 × 4 个遍数（N = 1…4）**。

## 二、结果

### 2.1 15 个工艺里 **10 个**单调递增，且**形状分三类**

| 工艺（τ / f / 间距 / v） | N=1 | N=2 | N=3 | N=4 | 形状 |
|---|---|---|---|---|---|
| 223 fs / 40 kHz / 4 µm / 20 | 5.2 | 29.6 | 36.7 | 40.4 | **1→2 跳变** + 饱和 |
| 4000 fs / 20 kHz / 2 µm / 15 | 15.8 | 23.9 | 28.8 | 32.2 | **平滑饱和** |
| 1000 fs / 40 kHz / 6 µm / 25 | 18.3 | 24.5 | 30.7 | 35.6 | **近似线性** |

⇒ **饱和形状随工况变**，不是单一规律。这正是 paper5.0 的 `full_core5` 想表达却（因只有终态标签）表达不出的东西。

### 2.2 另外 5 个非单调 —— 共同特征是**深度太浅**

`223/5/0.01/20`、`500/5/0.006/25`、`1000/2/0.002/10`、`2000/2/0.004/10`、`4000/5/0.008/10`
——深度都在 **5–8 µm**、f 低（2–5 kHz）、脉冲重叠少 ⇒ **噪声主导**，不是物理反常。
**建模时应按深度阈值筛掉。**

## 三、方法（含三个必须知道的坑）

```
.cag（Keyence 专有 ZIP）
  → CagHeightReader（输出与官方 CSV 字节级一致）
  → 去倾斜（线性项）
  → 连通域分槽（一个视场含 2 个槽）
  → 取【中间平缓区】算中位深度（形态学腐蚀 erode = 20 px ≈ 6.9 µm）
  → 用设计表的【中心Y】配对（图像 x 轴与设计 Y 轴**反向**：Y 大 ↔ x 小）
```

### 坑 1｜设计表的「脉宽」列**不是脉宽**，是 compressor 步数

```
compressor: 29400  36140  43800  58400  72900  87300  …  173500
τ (fs):       223    500   1000   2000   3000   4000  …   10000
```

映射见 `tools/compressor_pulse_table.py`（**越界直接报错，不外推**）。
⚠️ 还有一张表的**列名叫 `脉宽_fs` 但值也是 compressor** —— **判断列语义要看值域，不能信列名**。

### 坑 2｜槽的**边界有过深假象**，深度必须取中间平缓区

同一批槽对照（erode=20 vs erode=0），最大差 **6.19 µm**（中间区更浅）：

| 组 | 槽1 中间区 / 含边界 |
|---|---|
| 1 | −5.23 / −4.13 |
| **7** | **−13.35 / −7.16** |
| 14 | −6.03 / −4.24 |

### 坑 3｜配对必须用坐标，不能用文件名编号

| 做法 | 单调性 |
|---|---|
| 假设「x 小 = 先加工」 | 5/15 ❌ |
| **用设计表 `中心Y` 配对** | **10/15** ✅ |

## 四、还没做的（**不得当成已完成**）

1. **`D∞` 不可辨识** —— 4 个点拟合指数饱和 `D∞(1−e^{−kN})`，`D∞` 跨**3 个数量级**（13.9 → 9×10⁵ µm）。
   只有 **4/10 真正接近饱和**；其余在 N=4 时远没到头，`D∞` 是外推值。
   **建议：补数据到 N≥10，或只做 N≤4 内插、不报 D∞。**
2. **与 KEYENCE 官方 `mean_depth_um` 的交叉验证未通过** —— 与
   `laserloop_clean_v0_1/…/data/raw/SiC.csv` 对比，**编号体系或基准面不一致**，尚未解决。
3. **没有重复实验** —— 每个工艺只有 1 条曲线。
